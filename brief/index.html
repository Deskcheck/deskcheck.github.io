Deskcheck

Independent GUI verification for AI coding agents

An AI agent that edits a Windows desktop application cannot see whether its change works. Deskcheck gives it a deterministic runner that drives the real application with real OS input on an isolated VM and returns a verdict the agent cannot argue with: pass, fail, or no result.

The fleet

Every GUI run claims a Hyper-V VM under a lease, restores a clean checkpoint, runs, brings the evidence home and turns the VM off.

2,296fleet runs, 2026-10-14 to 11-11, every day
73 smedian run, p90 212 s
278runs on the busiest day
132distinct suites on 8 VM lanes

73% exit 0, 23% exit 1. Exit 1 includes tests written to fail first and mutation checks, so it is not a flake rate. A separate exit code marks a refused run (2%) so it is never counted as a product failure.

How it was built

  • 1,483 commits in four weeks; 99.1% of non-merge commits are co-authored by Claude. I set the architecture, the rules and the review discipline, and decided every merge.
  • Over 11,000 automated tests (C#, PowerShell, Python, C++, JavaScript, Delphi). The full gate is green except one known timing test.
  • In-app adapters for Delphi VCL and FMX, Win32 C++, Qt 6, Electron, Python, Java, WinForms and WPF, behind one documented protocol.
  • A Claude Code plugin with a telemetry Journal that records each agent session: builds, GUI runs, self-fixes, human interventions and reviews.

Not claimed

  • Outside the commercial product, L3 is one bug fix in Notepad++, not yet accepted upstream. No agent changed the other open-source applications.
  • No measured causal effect. Whether GUI verification makes agents fail less often or fix more of their own errors is a hypothesis, and the research I want to do.
  • Version 0.1.0 is not released yet; the repository is private until then.

Research question

Can an executable, independent GUI verdict serve as an oversight signal for coding agents, and as a verifiable reward? The plan is a controlled comparison of agent sessions with and without the verdict on seeded bugs, measuring undetected failures, self-corrections and human interventions from the Journal.
