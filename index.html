Deskcheck

AI-driven GUI testing for Windows desktop apps.

Coming soon

Deskcheck is an open-source (Apache-2.0) framework that lets AI agents drive, test and verify Windows desktop applications — Delphi/VCL, WinForms, WPF and more. It is being extracted from an existing product and prepared for its first public release.

  • Runner — a dotnet tool (deskcheck)
  • Adapters — UI Automation, Delphi
  • Fleet — Hyper-V test-VM tooling (Deskcheck.Fleet)
  • Agent skill — so coding agents can test desktop apps end to end

Follow along on GitHub or write to hello@deskcheck.pro.
